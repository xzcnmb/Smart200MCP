# 新 PLC：三气缸顶出 + 十路压力采集

本目录是**独立的新程序模板**，不引用 `cylinder_control_template` 或其他旧工程。
下载前必须在 MicroWIN SMART 的硬件组态中核对扩展模块槽位、模拟量地址和现场
气缸名称；程序中的“右/左/上”映射是暂定值。

## 暂定 I/O 映射

| 逻辑 | 地址 | 说明 |
|---|---|---|
| 双手启动按钮 1/2 | `I2.2`/`I2.3` | 终检运行按钮，需同时按下 |
| 停止/复位/自动 | `I0.1`/`I0.2`/`I0.3` | `I0.3=1` 为自动 |
| 急停健康 | `I0.4` | 假设急停常闭，输入为 1 表示正常 |
| 右缸伸出阀/到位 | `Q0.4`/`I2.1` | 暂按“右盖板压合气缸” |
| 左缸伸出阀/到位 | `Q0.6`/`I2.5` | 暂按“侧向定位气缸” |
| 上缸伸出阀/到位 | `Q1.0`/`I2.7` | 暂按“产品主气路接入气缸” |
| 泄气阀 | `Q1.6` | 1=泄气 |

上述三只阀均按**单电磁线圈、断电回缩**处理。若实际“左/上”气缸对应
`Q1.2` 或其他地址，只需在 `PRESSURE_TEST.awl` 的映射网络替换地址，不能
直接下载当前模板。

## 流程

1. 急停正常、自动模式、三缸均在原点且双手按钮同时按下，进入右缸→左缸→上缸。
2. 三缸动点到位后，`M20.0` 置位并采集 10 路压力 15 s（`T37`）。
3. 停止第一段采集，打开泄气阀 2 s（`T38`）；泄气期间恢复压力采集。
4. 泄气结束后继续采集 15 s（`T39`），随后保持 15 s（`T40`）。
5. 关闭三只气缸阀，回到待机。停止、急停或复位会立即撤销输出并回到待机。

## 模拟量地址（必须以硬件组态为准）

本模板暂用 `AIW16,18,…30,32,34`（第一只 AE08 的 8 路、第二只的 2 路）
保存到 `VW100…VW118`，**这些 AIW 只是占位，不能据此下载**。不同 CPU/模块
组态可能从 `AIW16`、`AIW64` 或其他地址起始；必须以 MicroWIN SMART 的“模块
地址/系统块”实际显示为准，并按通道顺序整体替换。

4–20 mA 变送器建议在模块中选 **4–20 mA** 量程。西门子原始值常见为
4 mA≈5530、20 mA≈27648，压力换算：

`P = Pmin + (Raw-5530) * (Pmax-Pmin) / (27648-5530)`

实际数值范围以 AE08 诊断/手册和 4/12/20 mA 实测标定为准，并对断线、超量程做报警。`VW100…VW118`
只是原始值缓存，便于 HMI 或数据记录使用。

## 接线要点

- 每个两线制变送器：`24 VDC+ → 变送器 +`，变送器 `− → AE08 通道 Ix+`，
  `AE08 M/COM → 24 VDC−`。三线制设备按厂家图，信号线接 Ix+、公共端接 M。
- 十个回路不要串联共用一个通道；每通道独立回路，电源 0 V 与模拟量 M 单点连接。
- 使用屏蔽双绞线，屏蔽层在控制柜端接 PE，远离电磁阀线缆；24 V 电源需校核
  总电流和回路负载（变送器最大负载电阻必须满足）。
- 急停必须通过安全继电器/阀电源硬切断，`I0.4` 只做 PLC 监控，不能代替安全回路。
