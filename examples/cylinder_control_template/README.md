# 两气缸控制模板（待现场 I/O 确认）

该目录提供 S7-200 SMART 的 AWL/STL 模板：`MAIN.awl`（OB1）调用
`CYL_CTRL.awl`（SBR0）。默认顺序为：A 缸伸出 -> B 缸伸出 -> B 缸缩回 ->
A 缸缩回。每步 5 秒超时，故障锁存于 `M0.2`，按复位 `I0.7` 且安全链正常
时清除。

## 默认地址

| 地址 | 含义 |
|---|---|
| I0.0/I0.1 | A 缸缩回/伸出到位 |
| I0.2/I0.3 | B 缸缩回/伸出到位 |
| I0.4/I0.5 | 启动 / 安全链正常（常闭回路逻辑 1） |
| I0.6/I0.7 | 自动选择 / 故障复位 |
| I1.0..I1.3 | A伸、A缩、B伸、B缩手动点动 |
| Q0.0/Q0.1 | A 缸伸出/缩回电磁阀 |
| Q0.2/Q0.3 | B 缸伸出/缩回电磁阀 |

程序假设每个气缸使用 5/2 双电磁阀并有伸、缩两个到位开关。若为单线圈
弹簧阀、地址不同或没有到位开关，必须先修改程序，不能直接下载。

急停必须通过硬件安全继电器切断阀电源；PLC 中的 `I0.5` 仅用于监控和撤销
输出，不能替代安全回路。
